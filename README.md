# VRChat AI 回复助手（MVP）

这是一个先把核心体验跑通的 Windows 原型：

- 右手扳机短按截取当前所有屏幕并开始识别。
- 使用 `E:\Documents\deepseek.txt` 中的 DeepSeek 视觉模型识别文字和语言。
- 生成三条目标语言回复，并在按钮中显示中文翻译。
- 点击回复后会粘贴并尝试自动发送目标语言正文，括号和括号内的中文翻译会被过滤。
- 如果 VRChat 聊天框当时没有获得焦点，正文仍会留在剪贴板中，可手动按 `Ctrl+V`。

`deepseek.txt` 约定为三行：

1. API 地址
2. API key
3. 模型名（可选）

当前版本是桌面陪伴窗口，适合先在 VRChat 桌面/头显并用时验证链路；后续可以把同一套核心逻辑接入 OpenVR Overlay，让窗口直接出现在 SteamVR 空间里。

运行：双击 `启动VRChat_AI助手.bat`（桌面窗口版）。SteamVR 版请双击 `启动VRChat_SteamVR版.bat`。

SteamVR 版本：SteamVR 正在运行时双击 `启动VRChat_SteamVR版.bat`。头显中只显示轻量 HUD；识别前不会显示任何卡片，识别成功后才出现视角正下方的识别内容和三张独立回复卡，选择回复后自动收起。卡片是无色透明玻璃底，黑色外框和黑字。

手柄操作（通过 SteamVR Input 动作注册）：

- 右手扳机短按：一键识别当前画面
- 右手扳机长按：关闭 HUD 并锁定识别；需要在 SteamVR 设置中重新开启
- 扳机按下和长按关闭都会先显示状态提示，避免无反馈。
- 左手确认键：确认当前回复，短暂高亮并反馈，然后发送目标语言正文；确认键候选只使用左手按键
- HUD 卡片不接收光标或鼠标点击，避免误选。
- 右摇杆上下：在 1-4 项之间移动选择；左扳机确认。
- 如果 SteamVR Input 动作没有激活，程序会自动读取控制器原始扳机和右摇杆轴作为兼容通道。

括号里的中文翻译不会被复制或发送。

设置和教程：SteamVR 版启动后，在 SteamVR 菜单中打开“VRChat AI 回复助手”图标即可进入设置。点击任意设置行后，右侧会显示候选项，直接点候选项选择；确认回复的候选项只保留左手按键。点击右下角保存。也可以双击“设置SteamVR快捷键.bat”打开桌面设置窗口。

备用测试：只有在 SteamVR Input 动作清单不可用时，才会启用 F8 备用键；正常运行时 F8 被明确禁用，避免误触自动识别。HUD 显示方式、发送方式和剪贴板识别开关都在 SteamVR 菜单的桌面设置里调整，不再占用手柄显示/隐藏按键。

显示样式：识别内容和三张回复卡分开显示在视角正下方。回复卡使用更高像素密度的思源黑体风格字体、黑色外框、黑色文字和白色半透明玻璃底；长回复会自动换行，不再把文字压到卡片外面。

识别成功后有三张回复卡和第 4 张“关闭该次会话”卡；发送方式可选键盘粘贴或 Tapi / VRChat OSC。

完整流程教程见 `示例教程_先跑通一遍.md`。离线自检运行 `E:\prod tool\python.exe self_test_steamvr.py`，会验证设置读取、正文过滤、三张回复和关闭卡渲染，不会调用 API 或向 VRChat 输入文字。

重新启动：再次双击 `启动VRChat_SteamVR版.bat` 只会停止并重启本助手自己的进程；不会关闭 VRChat 或 SteamVR。启动脚本使用已验证的 `E:\prod tool\python.exe`，不会每次启动重新安装依赖。
